# 第二章：三分鐘探索與免費本機對話

影片結束後，族人先說原有「前面就是西仔希克。這片森林，守護著我們的生活。」再接「現在開始你可以自由探索，了解這裡的環境」。介紹結束才開始180秒探索。期間帶路者留在原位，另外兩位原隊員在巨木左右各自小範圍走動，不顯示黃色箭頭，也不套用原跟隨走廊限制。

## 操作

- 可交談者包括 `Background people · local patrols` 下原有五位背景人物（兩名警察、兩名成年族人、一名小孩），以及巨木左右兩位原隊員，共七位。唯一帶路者與夜間人物不屬於自由交談名單。
- 水平距離3公尺內顯示交談按鈕；按 E 或點按鈕開啟，超出範圍提示消失。有多人時選最近一位。底部不再常駐顯示「靠近路邊人物……」操作字串。
- 自行輸入問題，按「送出」；可追問、用滑鼠滾動查看紀錄、按 Esc 或「離開」結束。交談時暫停玩家移動和目光操作，NPC 暫停巡邏並面向玩家；輸入文字中的 P 不會誤觸夜間快捷。
- 三分鐘是持續計時，交談不會重設時間。到時不接受新問題，已送出的問題可完成；回答顯示後保留5至13秒閱讀，接著唯一帶路者走到玩家當時視線前方、面向玩家說原本「沿著這條小徑，跟我來。不要離隊太遠。」，再轉身帶路並顯示黃色箭頭。没有新增集合橋段，也不把玩家傳回起點。
- 帶路者用森林地面及實體障礙建立的導航路徑，從玩家當下位置前往原巨木。落後超過5.5公尺時停下等待，黃色箭頭沿可走路徑排列；取消原本只適用由南向北隊伍的窄走廊限制，實體碰撞仍保留。兩位樹旁族人在進入巨木對話前停止巡走，保留查看倒地同伴與砍樹受驚演出。
- 服務尚未就緒或請求失敗時顯示明確提示，仍可離開或等時間結束；不把預寫台詞偽裝成模型回答。單次請求有75秒逾時上限。

## 本機模型與費用

使用免費開源的 [llama.cpp](https://github.com/ggml-org/llama.cpp) Windows CPU 版本 b11526，搭配官方 [Qwen2.5-1.5B-Instruct-GGUF](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF) Q4_K_M（Apache-2.0）。模型1,117,320,736 bytes，首次下載後，遊玩時不需要外網或 API 金鑰，也沒有雲端 token 費用。速度與回覆品質須以展示電腦實測為準。

目前安裝在 `D:/WusheLocalLLM/`；約1.1 GB的模型不放進 Unity Assets 或 Git。C 槽剩餘空間較少，這次使用 D 槽。模型及執行檔的 SHA-256 已和官方 Hugging Face LFS／GitHub release digest 核對。

`Assets/StreamingAssets/Chapter2LocalLLM.json` 保存本機服務及模型路徑。進入探索時，若 `http://127.0.0.1:18080` 尚未提供服务，遊戲會以隱藏視窗啟動這份已安裝的 llama-server；結束 Play Mode／離開場景時，只停止自己啟動的程序。若使用者先開了同埠服務，遊戲只連線、不擅自關閉。端點限定 HTTP loopback，沒有任何付費雲端備援。

換展示電腦時，可在專案根目錄執行：

```powershell
& .\Tools\LocalLLM\Install-LocalNPC.ps1 -Destination 'D:\WusheLocalLLM'
```

此腳本下載同一版本的執行檔及模型、驗證雜湊，並更新本專案的本機路徑；初次下載需約1.2 GB流量。之後正常 Play 即可。獨立 Windows 建置也需要在該電腦安裝同一模型，並確認建置輸出的 StreamingAssets 設定正確；本次不把外部模型打進遊戲安裝包。

## 角色與記憶

`Chapter2LocalDialogue.Persona` 定義警察、兩位成年族人與小孩的說話設定；`Resources/Chapter2LocalDialogueContext.txt` 保存目前劇情與可用背景資料。這份設定屬於遊戲創作，不能視為歷史人物原話。

每位 NPC 保留本次遊玩中最近三輪成功問答；人物間各自分開，離開再回來可以接著問。未做跨次遊玩或跨章節的永久記憶。第一版不需要 SQL 或向量資料庫，不訓練新模型。

模型只產生文字，不能移動人物、判定主線選擇、改檔或執行指令。提示要求繁體中文、簡短回答、依人物見聞回應、不預知後續劇情；Windows 端另做繁體字轉換。生成內容仍可能不準確，需要以實際試玩持續調整。歷史事實以核定資料為準。

## 驗證範圍

本版先做桌面文字輸入與字幕，未新增語音辨識、合成語音或 VR 虛擬鍵盤。既有 XR 移動和面板配置保留，但不代表已完成頭戴裝置打字操作驗收。新探索介紹句目前使用字幕等待，未新增配音檔。

本輪測試報告、模型雜湊與引擎截圖在 `_CodexBackups/chapter2_exploration_llm_20261009/`；正式驗證結果另記於 `PROJECT_CONTEXT.md`。`ui-diagnostic` 是停用本機服務及縮短時間的診斷輪，不能當作180秒與真實 LLM 回答的證據。

2026-10-09 的 `final-local-v2` 使用場景正式180秒設定，完成五位 NPC 的真實模型問答，驗證1.5公尺範圍、輸入 P 不跳章、探索時隊伍等待／箭頭隱藏、時間到接回原路徑並抵達巨木選項。這台 i5-1235U／16 GB 記憶體電腦的五次回答約1.0至19.5秒；之後重問小孩時能記得玩家自介「阿山」，另一位警察不知道此名字。整段探索含最後閱讀時間為184.94秒。

另以 `expiry-pending` 專門將倒數截止點設於真實請求送出後0.1秒，確認「尚在生成時到期」會等待回答及閱讀時間，再出發抵達巨木。這是刻意縮短的邊界測試，不能作為三分鐘計時證據。兩輪合併 `final-local-v2-checks.json` 為 passed=true，兩輪各 errors=0、warnings=1（既有停用音源警告）。繁體轉換另以250筆測試確認字串結尾正常；先前 `final-local` 的字尾亂碼已修正，畫面驗收以 `final-local-v2` 為準。

測試以 Unity Editor 驅動鍵盤事件、填入實際輸入欄並觸發送出，最後由測試工具移動玩家跟隨隊伍；引擎輸出畫面已檢查。不等同於實體 VR 操作、真人完整走圖或獨立執行檔測試。

2026-10-10 單人帶路更新驗證：`_CodexBackups/chapter2_single_escort_20261010/` 中 `review-east-v2`、`protect-full`、`final-west`、`final-behind-v2` 均 checks.passed=true、errors=0。右側、左側、巨木後方均實際走到原巨木；唯一帶路者到達鏡頭前約2.4m才邀請跟隨。正式180秒 `protect-full` 等真實LLM回答和閱讀結束後才迎接，兩位同伴後續可查看倒地者；另有砍伐至轉夜間的驗證。其餘方位輪將探索縮短15秒，只驗路徑及演出，不能當作180秒證據。七位人物交談3公尺內外邊界與底部操作字串移除均通過。實體VR與獨立建置仍未驗收。
