# 第三章：全程跟隊箭頭、群眾穩定與校內埋伏

日期：2026-10-21。依使用者最新兩張截圖與明確演出要求修改，取代先前「從校門外錯開衝入」的安排。仍使用同一第三章、原三路任務、命中規則與結尾分支。備份及本輪證據在 `_CodexBackups/chapter3_ambush_arrows_20261021/`。

## 行為

- **黃色箭頭**：補上山路交戰後的短林路、巴萬西側分段、比胡東側分段、三路校後匯合、共同撤離林路、「留下比胡」跟巴萬離開及扶行時前往達多所在接應處。保留駐在所、抵校與達多原有指引；保留的 `ch3部落與山林` 舊入口也接上同一箭頭。箭頭顯示在玩家與領隊之間，靠得很近或玩家已在領隊前方時不塞在人物腳下。坡面指引取實際路面高度並沿坡度旋轉；交接、受傷、重試、F6／F7／F8 與離開時清除。
- **校內左右晃動**：移除觀眾整個身體週期性左右轉的待機動作。繞障礙改為選定一個短繞行點後走完，限制步距避免低幀率跨過目的地，遇到動態阻擋稍候；背景角色若持續無法取得進展，停下躲避，通路真的清空才再走。兩名跑道學童的逃散目標改在柵欄內。召回同伴保留不能永久停靠的通路規則。
- **校內埋伏**：三名持械族人開始即位於校內分散位置，選線前隱藏且不行動。三個選項共用同一 `Choose -> Outbreak`：第一聲槍響後同幀啟動三名族人，從校內往人群移動，取消從校外依序入場。群眾仍依距離與角色錯開察覺、逃散；「同時出擊」不等於所有平民也同時動作。
- **持續混亂**：保留兩名成人的非血腥倒下，其他成人會驚慌、防護，與三名族人的攻擊動作形成分散的持續演出。演出持續到本路完成並開始校後集合，讓中央進場及左右外側都能看見。它不增加敵人數、分數或玩家傷害；原兩名可受傷警察繼續依正式戰鬥系統行動，平民保護不變。

上述埋伏位置、路徑、時序與對應動作是依本次要求安排的遊戲演出，並非宣稱已考證的歷史部署。參考原劇情摘錄第三章的突襲運動會、混亂與撤離段落，但本次明確方向優先。

## 驗證與界線

本輪測試以現有 Unity Editor Play Mode、Input System 與 CharacterController 驅動。攻擊使用正式武器入口；背景演出取樣時暫停兩名任務警察射擊，避免等待觀測造成角色死亡，並在報告註明。沒有把這類 fixture 當作自然敵方射擊證據。
