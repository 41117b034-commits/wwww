# 第三章：短交戰後連續步行至學校

2026-10-20。依使用者確認的路線製作：短交戰結束 → 同伴招呼帶路 → 林間轉彎與局部緩坡 → 先聽見運動會 → 看見操場 → 自己走到校門。

這段林路、距離壓縮、彎道與局部高差是關卡安排，不代表已考證的歷史地形或攻擊路徑。沿用單一 `Assets/Scenes/第三章.unity`，不新增章節入口。

## 行為

- 清掉山路三名巡警後立即保留移動與環視，不切鏡頭、不淡黑、不傳送玩家至校門。
- 巴萬實際走近並帶路，比胡沿隊伍走過的路線跟進。領隊只在玩家落後或後衛尚未跟近時等待；玩家走在前面不會讓落後的領隊停住。
- 林路由連續碰撞地面承接。緩坡使用獨立的地面高度與同行移動，不改動學校原有平面尋路器。
- 林路中段漸入運動會哨聲與掌聲，彎道後才露出學校。這些聲音是遊戲音效，不是歷史錄音。
- 玩家走到校門前時，學校角色在同伴當下位置接手，保留玩家位置、朝向、操作及單一武器選擇，再由原本靠近達多的互動開始三選一分工。
- F6／F7／F8 與空白鍵原有快速跳段仍保留；快速跳段是明確跳段操作，不屬於自然步行流程。

## 實作範圍

`Chapter3Flow` 在開始時把山路分區放至學校南方，學校與三條任務線仍使用原本座標。位移發生在山路啟動前，不在玩家行走中移動世界。`Chapter3Combat.WorldPoint` 處理短交戰出生、同伴、鏡頭與邊界的區域座標。

新增 `Chapter3SchoolApproach` 管理帶路、等候及無傳送接管；`Chapter3ApproachEnvironment` 建立連接地形與植被；`Chapter3ApproachAudio` 管理先聞聲的單一運動會音源。`Chapter3SchoolController.BeginFromApproach` 保留玩家與同行者位置；一般 F8 入口仍保留既有初始化。

沒有修改人物比例、掌軸、射擊／裝填規則、正式場景資產或全域品質。

## 本輪驗證

驗證證據與修改前備份：`_CodexBackups/chapter3_walk_to_school_20261020/`。

本輪使用原專案的 Editor Play Mode，從 F7 與明示 Carry 裝備開始，以實際 Attack／Reload 清掉三名巡警，再由 CharacterController 沿路行走，接近達多、選擇中央攻入線並確認進入交戰。巡警 HoldFire 是隔離步行檢查的明示 fixture；重試測試另以 Damage(100) 注入倒下，再用 Input System 的 R 重試。沒有寫入任務 Stage／Step 或用 Warp 略過林路。

逐幀量測涵蓋移動／環視旗標、CharacterController、黑幕透明度、玩家與同伴位移、地面、等候與恢復帶路、入校首次位置及實際 Transform 朝向。同伴換成原學校實例時保留位置與朝向；玩家沒有轉場位移。F6／F7／F8 中途離開另測清理與舊路線不再觸發。

音效以單一 AudioSource 連續播放。音量在 z=-82 至 -64 漸入，早於彎道後看見操場；「聽見哨聲」台詞仍在約 z=-76.36 觸發。取樣使用來源的 GetOutputData，涵蓋最初 20 秒；它不等於最終 AudioListener 混音或真人聆聽。`SchoolRevealed` 的 z=-37 是後段提示旗標，不能拿它當第一次實際可見操場的精確證據；先聲後景另對照正常視角截圖。

正常驗證圖必須等待 WaitForEndOfFrame，讓姿勢與表情裁切都完成後才渲染。早期 `before-end-frame-capture` 的頭頸缺片是取圖相位造成的中間狀態；新圖已確認完整，沒有因此修改正式人物、比例或 shader。`diagnostic-fence` 保留了校門來路木柵阻擋的失敗報告；現在入口的可見木柵與碰撞一起打開，路中央原有植被也已讓出通道。兩類中間證據均不作最終視覺驗收。

`diagnostic-rear-wait-measurement` 保留了重置測試的量測失敗：後衛沿領隊的原路繞掩體時，直線距離可能暫時增加，不能要求任意 0.8 秒內單調減少。最終跳段測試改成「領隊仍等候、後衛在 15 秒內沿路追到 3.4 公尺內」，保留卡住即失敗的時間限制；正式跟隊程式沒有因這筆量測而修改。步槍／獵刀完整報告仍保留各自已通過的原量測版本。
