# 第四章樹木貼地與坡面岩石修正

日期：2026-11-13。依使用者兩張實際畫面修正第四章環境，沿用既定第一批範圍。

原先 `GroundObject()` 以包含樹冠的 Renderer 外框中心作為定位點。樹冠不對稱，實際樹根會偏離地形取樣位置，斜坡上的高度差因此放大；原本留在定位點的樹幹碰撞也與可見樹幹錯位。岩石只用中心高度直立擺放，沒有處理坡下側的底面懸空。

新增正式 Editor 工具 `Assets/Editor/Chapter4Grounding.cs`，並由 `Chapter4SceneAuthoring.Build()` 在存場景前呼叫。現有第四章已直接套用並保存，沒有重建整個場景。

- 102 棵樹以實際網格最下方的小段頂點定位樹根，再對齊原配置點；維持樹木原有生長姿態，根部各取樣點至少嵌入地面約 6.5 公分。
- 樹幹 Capsule 的中心與半徑依根部校正；102 棵樹的碰撞中心與根部水平差最大約 0.0000153 公尺。
- 45 顆岩石依周圍實際地形取樣坡度，保留原方向，傾斜上限 38 度。34 顆傾斜超過 3 度，平地岩石保持接近直立。
- 岩石旋轉後重新檢查底部網格，使坡下側也嵌入地面約 10 公分。原有 MeshCollider 與模型一起移動、旋轉。
- 使用 Editor MeshData 讀取模型，沒有修改共用 FBX、mesh、材質或匯入設定。
