## LLM 診斷與修正

本輪實際服務為 **Local: wushe-npc / Gemma 4 E2B**，本機雲端設定 enabled=false。先前文件的雲端已啟用是歷史狀態。本輪沒有更改服務選擇、模型檔、金鑰、付費設定或第一／第二章預設參數。

- 原版兩問各等約 25.1 秒，均未取得 LLM 回覆，卻接上「我在聽」「我記住了」等泛用備援，直接重現答非所問。
- 原提示詞要求第一輪反問，實際暖服務測試也會轉問玩家，而未完整回答目的地。改成先直答具體問題、簡短場景事實，不強制反問；保留角色及不杜撰史實限制。
- 本機服務單獨的短問題約 2.9 秒，舊完整提示在 Editor 未 Play 時約 8.8 秒。遊戲運行下的一次服務紀錄，219-token 首問提示處理約 9.5 秒，暖快取後第二問約 5.2 秒；不是網路斷線就可概括的問題。CPU 推論、首次準備與遊戲負載是已觀察到的瓶頸。
- 開場預先啟動／準備服務。第三章限定較短提示、temperature=.35、有界輸出、15 秒等待上限；桌面請求期間暫限 20 FPS，完成／取消立刻還原，VR 不套用此限制。共享傳輸只新增可選參數與不含金鑰的耗時／HTTP code 診斷，其他章節沿用原預設。
- 備援依所在地、目的地、角色姓名、裝備或情緒回答，並明示為預寫回應；準備確認提問會先回答再詢問是否出發，不誤當同意。保留明確否定遣返與取消版本檢查。
- 本機冷啟動第一問仍可能超過 15 秒而採備援；本輪最終短測第二問取得 HTTP 200、正確回答巴萬·拿威，約 5.9 秒。**不能宣稱所有問題即時回答，也不能將備援算成生成成功。**
