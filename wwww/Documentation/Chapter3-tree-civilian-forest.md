## 原因與修改

1. 第一張圖底部字幕來自駐在所離開前的 `Gather`。正式場景 runtime 清查找到「駐在所林木 83」在 (-2.83,-93.45)，距縮短後出發路線中心只有 0.27 公尺。`Chapter3StationLink` 現在把原樹連同其碰撞平移 (3,0,-3)，移至路旁；沒有刪除整片樹林或改人物／鏡頭比例。
2. 女性與小孩原來沿 `escapeRoutes` 自行逃向出口，完成後 `SetActive(false)`，並非跟隨玩家的十人撤退隊。修改前長戰鬥觀察：吹哨前已有 13 人離場，撤退後達到 18 人離場。現在存活角色先在校內附近避難，吹哨時加入同一條出口路線，保持在玩家後方。抵達校後分散站位後保留在場，與原十名族人一起留在後方；不復活已倒地角色，不再走到出口後隱藏。主角與三領隊照原救援劇情前往林間接應處，群眾到齊不成為劇情門檻。
3. 林路 `MoveAlong` 遇到玩家站在比胡的最後目標點附近時，會直接 return，連靠近都不執行；受傷事件又要求比胡完成該路點。已重現玩家 (-3,92)、巴萬／達多到達前方、比胡留在 (0.01,84.77)、路線索引 3／2／3，55 秒後仍停在 Advancing。現在比胡會走到玩家身旁可站的空位，在實際到達位置受傷；不瞬移到玩家腳下。避讓玩家的繞行點會保留至抵達，防止每幀換邊繞圈。林路箭頭顯示前方路線，等待提示只在同伴真的等待落後玩家時出現。
4. 新跟隊人群另暴露共用轉角的佔位問題：靜態路點檢查忽略移動中的跟隊角色，但實際人群尋路會把他們當成障礙，導致對著被佔據的目標反覆搜尋。新增人物感知的轉角空位檢查，與實際尋路的碰撞規則一致；只改中途轉角，最後集合位置不提前算抵達。
