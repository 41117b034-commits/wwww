# 第三章：倒地、混戰、撤退與連續結尾

日期：2026-11-06。正式場景：`Assets/Scenes/第三章.unity`，Unity 6000.0.58f1。沿用使用者現有原專案。本次使用者確認撤退出口是目前通往林路的校後出口。

劇情參照 `Documentation/Story/賽德克事件劇情脈絡.pdf` 相關第三章內容；本次四張圖片與出口確認是修改依據。

## 四張圖片的修改

1. **警察倒地與音效**：`Chapter2Actor` 在倒地時放開原本的防守手臂姿勢、讓雙腿放平，使用實際變形後網格校正整個骨架的地面高度；校正可向上或向下，並在近遠模型切換時重新計算。最終姿勢仍快取，不持續烘焙網格。軍刀以地面高度落下。會場加入 IENBA 的 CC0 人群驚叫錄音，開戰時播放、對白期間降低音量、吹哨撤退後淡出，重玩會停止舊音源。
2. **不再繞三角形巡走**：刪除避難者與閒置戰鬥者循環切換三個近距離目標的行為。原十個族人名額保留，三個改用原有賽德克孩童模型與服裝，先走到西側柵欄旁躲避，蹲縮並抬手護頭；七名成人維持戰鬥，對手倒下後走向出口。原有二十名日籍觀眾保留自己的身分與模型，避難點不再循環走動。
3. **哨聲立即出發**：族人與存活觀眾收到同一哨聲就開始移動。出口旁使用分散集合位置，保留玩家通行的窄轉角；玩家通過出口後，族人才從後方接上原撤退與森林路線。達多仍領路。全程使用原碰撞與步行，不以瞬移、隱藏或重生補人。
4. **連續畫面**：去除第三章淡入淡出黑幕。留下比胡時，玩家留在接應棚，達多實際沿林路往返；不再把玩家或對話鏡頭切回傷點。接應棚後方使用原棚布材質設遮風布，莫那在隊伍進入森林前就位，之後繞棚走來。達多讓開入場視線，莫那再清點與結語。章末結算保留場景背景。

本輪證據目錄：`_CodexBackups/chapter3_continuous_battle_20261106/`。最終報告以根目錄 `report-rescue.json`、`report-leave.json` 及 `final-state.json` 為準；失敗、中間版本與修正前照片歸入 `diagnostics/`，不能當最終通過證據。

最終達多會場路線：救援 41 項、留下 39 項，共 80 項觀測檢查，兩份報告均 `completed=true`、`errors=[]`，生成時間均晚於最後 runtime 編譯。兩份報告的最大黑幕 alpha 均為 0、結尾玩家位移均為 0，十人實際走入森林，莫那步行速度約 2.7 m/s，F8 清理通過。第一輪出口曾被提早到達的人群堵住，已改成分散集合後重跑兩條路線；一次編譯／啟動 Play 重疊的工具測試失敗也已隔離，不列為通過證據。

這是 Unity Editor 驅動的流程驗證：戰前使用定位 fixture，四名會場警察與林路追兵以 `Hit(100)` 清場；森林傷點測試暫停救援更新，使玩家先實走到傷點，再恢復同伴行走；測試結尾禁止寫入正式完成存檔。未宣稱真人整章鍵鼠、獨立 exe、實體 VR、實際喇叭聽感或真實 LLM 測試。
