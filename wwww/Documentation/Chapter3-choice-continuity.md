# 第三章準備選項、常駐掩體與兩名教師修訂

日期：2026-11-11。對應使用者最新六張截圖；以下是本輪狀態，取代舊版四名教師支援與領武器後自由問答。

## 修改

1. 領武器後，巴萬的準備確認只有「好了」「還沒」兩個按鈕，也可按 1／2。此處不建立 LLM 問答，不顯示輸入框或送出。選擇前等待領取按鍵／VR 扳機放開，選擇只接受一次。字幕上移，避免與按鈕重疊；結束選擇後恢復字幕位置。先前駐在所開場的交談不是本次截圖中的準備確認，維持原流程。
2. 「好了」直接接既有出發台詞、同伴帶路及山路交戰。「還沒」接莫那走近與三段責備，收回武器後結束；不開啟後續山路／學校。Editor 退出 Play；獨立執行版保留原有停止進行的結尾畫面。
3. 四塊連續掩體岩石與六棵掩體樹改在駐在所預覽時建立，之後交戰初始化重用原物件。走近、兩句出發台詞和交戰交接之間，物件編號、位置、縮放與可見狀態不變，不再於台詞結束後突然長出。
4. 土路邊界多留 0.35 m 餘裕，駐在所到山谷的接縫加上逐漸展開的路肩。交戰接手後，入口仍使用相同的轉角邊界，可回走；保留 CharacterController 與既有石頭／樹木碰撞。
5. 運動會背景聲從林路較遠處開始漸入。比胡說「聽，前面是運動會的哨聲。沿這條路繼續走。」時，哨聲／掌聲底音已播放；進校門後使用同一音源與播放位置。沒有新增網路音效服務。也補正 `Chapter3SchoolApproach.BeginWalk` 遺漏的舊句，使用已核准且已有四角色配音的「前面的路通了，跟我沿林路走。比胡，留意後方的動靜。」
6. 教師原模型把下顎裁掉，另加的頸部沒有形成連續表面。現在保留下顎、縮短耳後髮尾、重接頸部、平順耳後到衣領輪廓，逐三角形保留臉部 UV；頭頸網格檢查為 0 開放邊、0 非流形邊。正式 FBX 約 9.25 MiB，原 meta GUID 與皮膚貼圖雜湊保留。模型仍以既有成人素材修整，非照片級重建。
7. 校內確切為兩名警察與兩名男教師，各自有一名族人對手，共四組交戰。教師取原日籍角色索引 3、6；另外兩名原男教師與女教師、學童往校內避難。兩名交戰教師仍須玩家正常武器支援才能擊倒；兩警與兩教師完成後才能吹哨。HUD 顯示警察 0/2、教師支援 0/2。
