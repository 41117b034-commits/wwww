# 第三章植被、撤退同行、步速與射擊

日期：2026-11-06。依使用者兩張截圖及兩項操作問題，修改正式第三章的執行程式。

## 修改與原因

- 懸空植被：`Chapter3StationLink` 接通駐在所與山路時，裁掉世界 Z > -93 的舊駐在所山坡，並隱藏該區舊樹木，卻漏了 `路側蕨草`。正常連續進場保留駐在所顯示，原 `路側蕨草 6` 因而浮在短交戰路面上約 1.728 m；F7 捷徑會隱藏駐在所，單測捷徑看不到此問題。現在同時隱藏裁切區的舊蕨草，保留駐在所庭院及未裁切區植被；正式場景及原素材不變。
- 十名族人：舊撤退路線在校後固定集合位置結束，人物隨後停止跟隨，三名領隊和玩家進林路時他們仍留在校後。現在保留原十人及校內剩餘轉角，各自實際走到校後後，按抵達順序進入玩家後方兩列隊伍，沿林路持續同行到接應處。到校後的紀錄與後續位置分開保存，不會因離開集合點而失去已實際到達紀錄。既有尋路、人物碰撞、停等與 F8 清理保留。
- 回歸發現桌邊卡點：原人群行走膠囊半徑 0.23 m，撤退尋路卻使用領隊的 0.36 m 膠囊；平時合法站在桌邊的人切換撤退時會被較大的尋路膠囊視為嵌入桌面。人群尋路現在共用實際行走的半徑與上下端點，領隊仍用原尺寸，實際碰撞沒有縮小。獨立桌邊重現確認能沿空隙走出、朝桌面走仍被阻擋。初次定位工具曾停用群眾管理器而連帶停用人物，該兩份未通過工具輸出不作產品前後對照；以保持群眾活動的 `report-navigation.json` 為準。
- 領隊：達多撤退時恢復原帶路／落後停等模式；十名族人繼續跟在玩家後面。巴萬、比胡仍走各自實際出口路線，三人到齊後一起進入林路。
- 結尾過場：後方隊伍以最後一個玩家可控制的位置為跟隨目標；留下比胡的演出將觀看位置移回傷者時，隊伍仍繼續走向接應處，不因鏡頭切換而整隊折返。
- 一般步速：`Chapter3Player.WalkSpeed` 由 2.4 調為 2.7 m/s，玩家、主要同伴及十名撤退族人共用。瞄準、扶傷與緊急接應等特殊動作維持既有速度。
- 射擊：仍只接受動作最後 0.25 秒的短緩衝，但已接受的單次按鍵保留到該次動作完成，不再被慢影格直接跨過期限而吞掉。裝填改用同一遊戲時鐘的絕對完成時間，在讀取當幀輸入前完成裝彈，移除協程晚一幀恢復造成的額外空檔。保留單發裝填 2.6 秒、槍械復位 0.48 秒、刀 0.68 秒、早按提示、單次步槍觸發及取消規則。
