# 第三章：注視玩家、清場接續、群眾朝向與玩家抵達會合

2026-11-01，依使用者最新四張實玩截圖修改正式第三章 runtime。參考固定劇情摘錄第 8–10 頁；當次要求取代先前「十名族人與三名領隊全部到齊才能繼續」的設計。

## 原因與修改

1. 達多岩石後的蹲姿疊加了脊椎／頭部向下傾斜，說話時只有身體轉向玩家。現在以原模型的臉部方向校正頭骨，在達多說話時平滑看向玩家攝影機；保留蹲姿、雙手置於腿上的位置，離開掩體後照常行走。
2. 四組警察可自由接近，但舊 `UpdateAssault` 每組擊倒後仍同時要求達多走完路線、玩家回到該組舊集合位置。已移除這個回頭條件；清掉該組便接續進度，四名都倒下後達多自行走向撤退出口。玩家仍以 E 吹哨通知全體撤退。若達多落後，保留通過校門／場內器材的安全轉角，不直接朝遠方出口斜穿。吹哨不重設已經走過的路段。
3. 女性與小孩的烘焙網格正面是局部 -X，背景走路骨架卻以 +Z 為前方，造成側身移動。只在這兩種來源建立 runtime 群眾時將幾何與碰撞中心轉正，再建立走路骨架／權重；不是單純旋轉角色根節點。既有十名族人的原骨架路徑不套用此校正。
4. 舊撤退同時等待十名族人抵達；舊會合再等待三名領隊，任一人延遲就無法開始林路事件。現在玩家實際走入校後會合範圍就立即播放接續台詞。族人仍沿原路走，抵達後的放行狀態會保留，玩家離開集合範圍也不會重新把後方族人鎖住。三領隊在對話期間繼續走完各自的學校出口路線，再個別交接給林路行走；不傳送領隊、不要求十人完成集合。
