## 本批可玩的流程

從既有章節選單點選「第四章」，載入 `Assets/Scenes/第四章.unity`。玩家出現在山林避難營地，畫面顯示「沿山路前往集合地」，可沿連續土路自行步行。

路線順序為：避難營地 → 第一個短岔路 → 中段休息空地 → 第二個短岔路 → 岩肩 → 集合地。兩條支路是可進入及折返的短死路，末端分別以岩石與倒木阻擋。主路以緩坡和彎道銜接，沿途保留路肩與回看後方的空間；沒有必須照順序碰觸路點才能抵達的隱藏關卡。

起點配置布棚、岩石、木箱、木桶、木凳及空擔架；集合地有棚架與「集合處」標記。樹幹、岩石、營地實體道具及地面具碰撞，低矮蕨草不阻擋玩家。遠景霧是山林天候氣氛，本批沒有毒氣效果。

進入集合地時，須實際接地、距離中心不超過 3.2 公尺，且高度差不超過 1.2 公尺。抵達後顯示「已抵達集合地」，可選「繼續探索」或「返回章節選單」。繼續探索不會重複跳出抵達畫面；離開後重新進入第四章則回到起點，重設本次抵達狀態。

本批不包含 NPC、開場台詞、第三章比胡結果承接、隊伍跟隨與示意、毒氣攻擊、同伴倒地、歐冰聯絡、兩種結局、史實後記或章完成保存。這些依原規劃留在第 2–5 批。

## 操作與狀態

| 操作 | 功能 |
| --- | --- |
| WASD | 以 2.4 m/s 步行，斜走速度不加倍。 |
| 按住滑鼠右鍵 | 環視。 |
| 左鍵點一下遊戲畫面 | 固定滑鼠以持續環視，略過捕捉首幀的滑鼠位移。 |
| Esc | 開啟或關閉暫停選單；開啟時停止移動並釋放游標。 |
| 繼續／繼續探索 | 關閉選單，恢復移動。 |
| 返回章節選單 | 載回 `選擇章節ˊ`。 |

玩家使用獨立 `CharacterController`，沒有沿用第三章的戰鬥或劇情控制器。沿路不可見資料點只記錄跌出地形後的回復位置，不代表劇情檢查點完成；玩家高度低於路線最低點 12 公尺時回復到最近記錄位置。

已接入頭部追蹤、左搖桿移動、右搖桿轉向及凝視加右扳機選單的 XR 程式路徑，但本輪沒有實體頭戴裝置驗證，不以桌面測試推定 VR 通過。

`Chapter4SceneController` 不讀寫前章結果，也不寫入第四章完成或結局。抵達狀態僅存在於當次場景實例，返回選單與重進不會覆寫既有存檔。
