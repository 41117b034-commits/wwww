# 第三章：即時進掩體、玩家帶隊撤退與連續近戰

2026-10-30，依使用者四張截圖及校內近戰要求修改正式第三章所用 runtime。固定劇情參考為 `Documentation/Story/賽德克事件劇情脈絡.txt` 第 8–10 頁；本次是遊戲演出與互動調整，沒有新增史實主張。

## 五項修改

1. 山路兩句說明結束即開始戰鬥，刪除必須走到指定 z 座標的條件。玩家保留位置及鏡頭，第一個戰鬥畫面即呈現原已選武器且可攻擊。巴萬立即實走到原左石，比胡到原 `交戰道路林木 49` 後，抵達才蹲下。沒有傳送同伴，也不會把選獵刀的玩家強制換成步槍。
2. 達多在學校預載及正式抵達時即位於既有 `可碰撞岩石 0` 的林路側，蹲低藏身。靠近仍啟動原分次分工字幕及三路選擇；選任務後站起並走入學校。
3. 吹哨後由玩家帶路。達多與原十名族人沿實體通道跟進；匯流後以路線距離限制達多落後約 1.8 公尺、族人至少約 3.4 公尺，轉動鏡頭不會反轉隊伍。黃色箭頭改顯示玩家前方路線。抵達校後才分散進各自站位，另兩路領隊維持各自側路會合。
4. 修正撤退尋路與人物碰撞互相矛盾、轉角目標被逃跑人群佔用，以及人物貼身時網格第一步找不到出口的情況。轉角可改選附近可通行位置；已重疊的人物只能以正常步速分開，每一步仍檢查碰撞。最後集合點不改，不用時間到就過關；原十人與三領隊實際到齊才進救援。
5. 校內四組近戰移除固定時間換角落的巡迴方式。由對手距離、揮刀、格擋、受擊與收刀階段驅動短距離進退、橫移與反擊；包夾組會朝實際攻擊者轉身。刀勢有不同方向，族人也有戒備與格擋姿勢。四名警察仍只以族人為攻擊目標，族人可削弱警察，最後擊倒由玩家完成。
