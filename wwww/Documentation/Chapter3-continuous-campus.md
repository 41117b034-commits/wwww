# 第三章：連續山路與四組校內混戰

工作開始於 2026-10-29，驗證跨至 2026-10-30。依使用者六張實玩截圖修改正式 `Assets/Scenes/第三章.unity` 所用 runtime。

## 六項需求

1. **駐在所到短交戰連續銜接**：`Chapter3StationLink` 在進場前將駐在所出口與既有山路接在同一座標空間，建立可行走土路、裁切重疊地形。領武器後的兩句山路說明結束，沿用玩家位置、鏡頭及同伴當下位置交接，不呼叫原先淡出、傳送和黑幕開場。F7 仍為直接進入交戰的測試捷徑。
2. **縮短領武器後腳程**：原實走約 53.31 公尺，新的出發路線約 27.81 公尺。領隊出發步速由 1.75 改為 2.4，後方比胡跟進為 2.7；玩家仍以原 2.8 速度自行走，落後仍會等待。不是放大人物或改變視角比例。
3. **刪除達多路線兩名對玩家瞄準的警察**：選達多後只保留四組可擊倒的近戰警察。每段協助一組，四組皆處理才可吹哨撤退；重試保存各警察生命、傷勢、位置與已完成段落。巴萬／比胡側路既有任務另計。
4. **不同形式的混戰**：四組分別為移動交鋒、追逐後轉身反擊、兩人包夾、三人逼退。使用原十名族人中的七人，不額外生成撤退人數。警察與族人實走、揮刀、受擊；警察的 `AlliesOnly` 讓近距離玩家也不會成為校內這四人的攻擊目標。族人能削弱警察，最後擊倒由玩家完成。集合點避開來賓桌、遮棚柱與交戰人群。
5. **族人外觀差異**：十人分用三種既有原住民骨架／蒙皮外觀；只複用視覺與步態，不複製領隊任務、語音、對話或身份。人物高度保持既有族人比例。
6. **校後匯合**：領隊繞開站在路線上的玩家時，保留選定繞行點，走完才重新接路，避免逐幀改向。集合仍要求原十名族人與三位領隊到位；等待另外兩隊時會明示右側比胡或另一隊尚在路上。後續接既有比胡受傷／救援流程。

固定劇情參考：`Story/賽德克事件劇情脈絡.txt` 第 8–10 頁。四組人數、位置、動作及壓縮路程均為遊戲安排；本輪沒有新增史實引文。
