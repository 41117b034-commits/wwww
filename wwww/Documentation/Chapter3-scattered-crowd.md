# 第三章：校內群眾散布與兩組持刀控制

日期：2026-10-21。這次依使用者最新截圖修正校內背景演出，取代上一版十組整齊交手與二十人全數倒地的安排。具體站位、人數及動作仍是遊戲演出設定。

## 本輪修改

- 校內十名族人全程站立，不安排族人倒地。舊版「男教師」雖換了衣服顏色，仍帶著族人披布、飾品，因此撤掉這個替代模型。十名日籍成人現在使用現有日本女性和服模型，角色標示為女教師與家屬；沒有假稱新增男性模型。
- 日籍群眾仍為二十人：十成人與十學童。兩名成人由兩名族人在身後持刀控制，其餘為十二名分散倒地、六名驚慌逃離。成人／學童受擊只呈現非血腥倒地，沒有新增血液或肢體破壞。
- 取消左右對稱格點，改成操場各處不同位置、朝向及左右側倒姿。其餘族人完成接戰後分散，不在屍體前循環揮刀，也不排成十組持刀對站。
- 六名逃跑者走不同路徑，經校後既有開口離開；只有真正到達出口後才隱藏。兩名原跑道學童維持槍響當下交接，避免重複人物。
- 保留「選定任一路線後，第一聲槍響同幀啟動十名族人」。兩組架頸使用真實手臂骨架與手持刀姿態，僅針對其配對成人允許較近站距；其他人、柵欄與場景障礙仍避讓。
- 本輪未改槍械、警察傷害規則、後續比胡救援劇情或場景資產。
