# 第三章六張截圖修訂

日期：2026-11-10。正式場景為 `Assets/Scenes/第三章.unity`，Unity 6000.0.58f1。依使用者本輪六張截圖及其最後確認的台詞、配音授權處理；劇情參考為 `Documentation/Story/賽德克事件劇情脈絡.pdf` 第三章。前輪日籍追擊／師生受害設定不取代最新「兩組警察、兩組男教師、日本角色留校」要求。

## 截圖對應

1. **駐在所屋頂的棕色尖片**：實查是相鄰山谷地形在 z=-93 被截斷後，11 公尺高側坡露在約 5 公尺屋頂後方；不是屋頂多了一根木頭。`Chapter3StationLink` 讀取駐在所地形接縫，讓山谷從同一高度起逐漸銜接原山坡，連同該區樹木、蕨草高度及網格碰撞一起對齊。屋頂本身不需刪除。
2. **巴萬、比胡低頭說話**：山路同伴沒有校園控制器，原先以校園玩家為前提的注視程式未生效。掩體姿勢現在明確接收玩家相機；說話時身體與頭部朝玩家，保留原蹲姿、手腳和臉部裁切更新。
3. **出發台詞**：改為「前面的路通了，跟我沿林路走。比胡，留意後方的動靜。」使用者已明確同意只將此句送至既有 Microsoft Edge 語音服務。新增巴萬、比胡、達多、莫那四份固定配音，catalog 685→686；原 685 項、成熟音色參數及族語選項保留。
4. **模型與持刀**：截圖中的黑西裝人物實為男教師。教師 FBX 修整完整後頸、下顎與衣領銜接，清除後頸殘留飾物，增加較自然的衣褶、袖扣、口袋與背縫，修整持刀手指。遊戲西裝提高可讀性，背縫改成同色深線，避免白色細棒般的外觀。四名交戰男教師都以右手持刀、左手護身；倒下後刀落在身旁，重新進章收起刀具。警察另加既有法線細節、布紋與較低反光的專用材質，限第三章使用。保留原教師 FBX GUID。
5. **全體族人撤離**：確認原七名成人、三名孩童，共十個原角色，從校內開始，哨聲後實走到校後，再跟進森林接應處。沒有將日籍制服學童改稱族人。原二十名日籍師生與校內兩名警察留在學校；沒有新增校外原住民婦女或複製撤退名額。
6. **警察預先埋伏**：進入林路階段時警察已在左側既有岩石後，身體被遮住，接近轉角前能在周邊視野瞥見頭部。以該角色自己的步槍、槍口和空間音效打中比胡，隨後以 1.55 m/s 繞出岩石；選擇救援或離開均沿用同一角色。死亡重試恢復已現身的檢查點；重新進章清除埋伏狀態。

## 驗證範圍

以現有 Unity Editor、正式第三章場景執行驅動驗證。兩個結尾使用校園指定入口、警察停火／Hit 清場以隔離教師支援、正常玩家武器與 CharacterController 移動、Input System 按鍵，以及暫停救援 Update 讓玩家實走到原受傷點的 fixture。教師模型攝影會暫時改相機位置；倒地刀具測試單獨設定倒地進度。測試禁止寫入玩家結局存檔。

救援與留下分支均實際驗證原十人、三位領隊、校內二十名日本角色及兩具警察遺體的連續狀態。受傷前警察身份、部分遮蔽、槍口射線、同一警察步行現身、選擇後身份保留、死亡重試及重進章亦納入。救援原隊伍最大取樣步速 2.701626 m/s、黑幕 alpha=0；警察實走 11.57733 m，最大取樣步速 1.550394 m/s，槍口到比胡射線無岩石阻擋。留下分支 22 次觀望視線樣本無角色／場景遮擋。

配音測試關閉兩個線上旗標：四角色首次載入約 25–28 ms，字幕與播放同幀，音源非靜音約 0.109–0.162 秒內被逐幀觀測到；重播使用快取。此為 Unity 音源與 PCM 觀測，不是實際喇叭延遲量測。掩體兩人抬頭穩定後最大頭部視線誤差約 0.020 度；量測時暫持 speaking 狀態。
